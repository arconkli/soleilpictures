# Shot list template

> This shot list template pairs a reference frame with the three things a crew actually needs beside it: shot and lens, camera movement, and notes. Every box is labelled until you fill it. Add it to a board, then stamp a copy for each setup and the numbering follows.

_Source: https://clusters.soleilpictures.com/templates/shot-list-template · Updated 2026-08-27_

## The layout

Database row · 1 left / 3 stacked — 4 boxes.

| # | Label |
| --- | --- |
| 1 | SHOT + LENS |
| 2 | FRAME |
| 3 | MOVEMENT |
| 4 | NOTES |

Each label shows only while its box is empty, and is never written into the box.

## A shot list that shows the shot

Most shot lists are a spreadsheet, and a spreadsheet cannot show you the frame.
This template gives the reference image half the row and stacks the three fields
a crew reads on the day beside it. On set that means one glance answers both
"what are we shooting" and "how", instead of a row of text somebody has to
translate back into a picture.

## Beside the storyboard, not in another file

The list belongs next to the frames it describes. Put these rows on the same
canvas as your storyboard panels and the schedule, and the whole scene is one
view instead of three documents that drift apart.

## Frequently asked questions

### How do I add a row for every setup?

Select the row and click the "+" handle on its bottom edge to stamp a linked copy, which carries the same labels. The matrix generator lays out a whole day at once.

### Do the shots number themselves?

Yes. Put a numbering tag in a field and each row renders its own number based on where it sits on the canvas, so inserting a setup renumbers the ones after it automatically.
