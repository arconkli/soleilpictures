# Storyboard template

> This storyboard template is a three-panel grid: one wide establishing frame across the top, two beats beneath it. Each box carries a label until you fill it, so a stranger opening the file knows what goes where. Add it to Clusters in one click, then drop in stills, sketches or captions.

_Source: https://clusters.soleilpictures.com/templates/storyboard-template · Updated 2026-08-27_

## The layout

Storyboard · 1 top / 2 bottom — 3 boxes.

| # | Label |
| --- | --- |
| 1 | ESTABLISHING |
| 2 | ACTION |
| 3 | REACTION |

Each label shows only while its box is empty, and is never written into the box.

## Why one wide frame over two

A sequence rarely reads as equal boxes. You establish, then you cut — so the
template gives the establishing shot the full width and splits the beat
underneath it. Drag the divider if your scene wants a different balance; the
panels re-flow and nothing you have already dropped in moves.

## One panel is not a storyboard

A scene needs more than three frames. Select the grid and the directional "+"
handles appear on each edge: click one and you get an identical, linked panel
beside it, carrying the same labels and any numbering slate you have set up.
Change a divider on one and the whole row re-cuts together, so a six-panel
sequence stays a grid rather than six drifting rectangles.

## Frequently asked questions

### Can I add more panels?

Yes. Select the grid and click a "+" on any edge to stamp a linked panel beside it, or use the matrix generator to lay out a whole page at once. Stamped panels carry the same labels.

### What if I want a different panel layout?

Drag any divider to re-balance the frames, or split a panel in two. You can also pick a different template later — the images and captions you have already added carry across to the new shape.
