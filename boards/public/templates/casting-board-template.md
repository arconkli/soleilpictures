# Casting board template

> Nine headshots laid out three across, with a row for each tier — leads on top, supporting in the middle, background at the bottom. Everyone reading for the same part sits on one line, which is the comparison a director is actually making.

_Source: https://clusters.soleilpictures.com/templates/casting-board-template · Updated 2026-08-27_

## The layout

Contact sheet · 3 × 3 — 9 boxes.

| # | Label |
| --- | --- |
| 1 | LEAD |
| 2 | LEAD |
| 3 | LEAD |
| 4 | SUPPORTING |
| 5 | SUPPORTING |
| 6 | SUPPORTING |
| 7 | BACKGROUND |
| 8 | BACKGROUND |
| 9 | BACKGROUND |

Each label shows only while its box is empty, and is never written into the box.

## Frequently asked questions

### Can I put a name or a tape link under each headshot?

Yes. Split a box in two and put the photo above and the text below, or drop a link card straight into the box — a cell takes an image, text, a link or a video.
