# Links and mentions

> Type @ anywhere you can write to mention a cluster, document, card, tag or person. Mentions become real links with hover previews, and they register as backlinks so the thing you mentioned can show everywhere it is referenced from. URLs and names of things you already created are detected and linked automatically.

_Source: https://clusters.soleilpictures.com/docs/organize/links-and-mentions · Updated 2026-08-08_

Mentions are how separate parts of a workspace find out about each other.

## Mentioning

Type `@` in a [note](/docs/canvas/notes), a [document](/docs/documents), a card
title or a [message](/docs/collaborate/messages), then start typing a name.

You can mention a cluster, document, card, note, image, palette, group, tag,
URL or person.

The result is a real link. Hovering shows a preview appropriate to the type — an
image shows the image, a board shows its thumbnail, a person shows who they are.
Clicking navigates.

## Automatic links

Two things happen without you asking.

**URLs** typed or pasted become links, with previews on hover. Pasted onto an
empty canvas, a URL becomes a full [link card](/docs/canvas/cards) instead.

**Known names** are detected. Once a tag or entity exists, later occurrences of
its name in your writing are quietly underlined and connected. Writing "Diner"
in a note after creating a Diner entity links the two without any `@`.

## Backlinks

The reverse direction, and the reason mentions are worth the keystroke.

Anything that gets mentioned can show a **Referenced by** panel listing
everywhere it was mentioned from — documents, notes, cards, messages, boards.

A location entity ends up listing the script scene, the reference wall, the
schedule entry and the message thread that all pointed at it. Nobody built that
index; it is a by-product of writing normally.

## Deep links

**Copy link** on any card gives a URL that opens the board with that card
selected and in view. Paste it into a message, a document or an email.

Deep links carry the target through sign-in, so a recipient who is not logged in
lands in the right place after authenticating rather than at the home screen.

## Where mentions work

| Surface | `@` mentions | Auto-links | Backlinks |
|---|---|---|---|
| [Notes](/docs/canvas/notes) | ✓ | ✓ | ✓ |
| [Documents](/docs/documents) | ✓ | ✓ | ✓ |
| Card titles | ✓ | ✓ | ✓ |
| [Messages](/docs/collaborate/messages) | ✓ | ✓ | ✓ |
| [Comments](/docs/collaborate/comments) | ✓ | ✓ | — |

Mentioning a **person** in a comment or a note notifies them. See
[Notifications](/docs/collaborate/notifications).
