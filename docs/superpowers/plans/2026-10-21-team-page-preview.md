> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the preview site, an admin opens Settings › Preview › "Team plan: open a test team as Owner / Admin / Member / Unpaid", and the real app shows the Team page the owner picked (direction B: a page of its own with tabs People · Seats & billing · Joining) for a test team, Northlight Films, plus the team's section at the top of the workspace menu. **Architecture:** The page renders a `TeamSnapshot` (`boards/src/lib/teamModel.js`, header comment). The page is lazy and carries its own CSS, so the signed-in app's CSS budget doesn't move. Task 1 (the model, the sample, the preview store and their unit tests) is DONE and passing; Tasks 2 and 3 build on it.

**Tech stack:** React 18 (function components, hooks), plain CSS with the app's tokens, Phosphor icons through `boards/src/components/Icon.jsx` and `boards/src/lib/icons.js`, `node --test` unit tests, Playwright specs against the Vite dev server.
